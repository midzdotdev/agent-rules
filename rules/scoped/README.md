# Scoped rules

Files here are loaded when their topic matches the current task. Organise
by topic, one file per concern:

- `ctx7.md` — using context7 for library documentation
- `typescript.md` — TypeScript-specific preferences
- `git.md` — git/PR conventions
- (etc.)

These are promoted from `learnings/` once a correction has recurred enough
to justify a permanent rule. Until then, the learning entry is the source
of truth.
