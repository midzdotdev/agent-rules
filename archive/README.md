# Archive

Old learnings and rules that no longer apply, or never recurred enough to
justify keeping in the live tree.

Entries arrive here via:

- The quarterly archive audit (`.github/workflows/archive-audit.yml`) — an
  automated PR moves stale `learnings/` entries here.
- A manual decision recorded in a PR: "this is superseded by X".

**Ignored by agents during normal operation.** The directory exists only
for history; reach for it when reviewing how an opinion evolved.
